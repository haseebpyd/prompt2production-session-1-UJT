Chapter 3: Prompt Engineering / Image Generation

3b. Image Generation by Prompting

Structured, visual prompts for Google Gemini image generation (Nano Banana).

Source: Panaversity — Image Generation · Tool: gemini.google.com

Core Principles

Specificity

"Hyper-realistic studio portrait" beats "a nice photo"

Visual hierarchy

Subject → environment → lighting → mood

Photo language

85mm lens, f/1.4, Rembrandt lighting, editorial style

Prompt Anatomy

  1. Subject description (who/what)
  2. Pose / action
  3. Environment / background
  4. Lighting (type, direction, mood)
  5. Style (aesthetic, genre)
  6. Technical specs (camera, composition)
  7. Mood / atmosphere

Example: Professional Branding Portrait

Upload a reference photo in Gemini, then use this prompt structure:

Hyper-realistic full-body portrait of the uploaded photo,
standing against a smooth light-gray wall. Hands in pockets,
relaxed posture. Studio lighting, premium clarity.

Wall graphic: stylized vector portrait + bold name typography.

Mood: modern, minimal, premium personal-branding.

Example output from Panaversity tutorial

Best Practices

  • Ground the subject: "of the uploaded photo" for consistency
  • Specify pose explicitly — avoids random body language
  • Include context (wall color, studio vs outdoor)
  • For branding: add typography and graphic elements in the prompt
  • Iterate one variable at a time (lighting, then background, then text)
