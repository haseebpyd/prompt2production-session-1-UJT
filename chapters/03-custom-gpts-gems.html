3f. Custom GPTs & Gemini Gems

You've learned to write great prompts — now package them into reusable assistants. No code required.

Tools: ChatGPT Custom GPTs · Gemini Gems

Why This Is Your Next Step

A one-off prompt lives in your chat history. A Custom GPT or Gem saves your instructions, knowledge files, and tone so you (and your team) get consistent output every time. Think of it as deploying your 6-step framework as a product.

Part A — Create a Custom GPT (ChatGPT)

Requires ChatGPT Plus or higher. Budget ~15 minutes for your first build.

  1. Open the builder. Go to chatgpt.com/gpts → click Create (top right).
  2. Switch to Configure. Skip the conversational "Create" tab — use Configure for direct control over every field.
  3. Name & description. Use a clear functional name (e.g. "Sprint Planning Coach"). Description = one sentence on who it's for and what it does.
  4. Write Instructions. Paste your system prompt (role, task, constraints, output format). This is your 6-step framework in one block — see copy-ready template below.
  5. Conversation starters. Add 3–4 example prompts users can click: "Review my sprint backlog", "Draft acceptance criteria for this story", etc.
  6. Upload Knowledge (optional). Add PDFs, TXT, or DOCX — style guides, context.md, API specs. The GPT retrieves relevant chunks on demand.
  7. Configure Capabilities. Toggle only what you need: Web Browsing (live docs), Code Interpreter (data/files), Image Generation. Turn off the rest.
  8. Test in Preview. Run 5 realistic prompts in the right panel. Fix wrong tone, format, or hallucinations — edit Instructions and retest.
  9. Publish. Click Create → choose Only me (private), Anyone with a link (team), or Public (GPT Store).

Advanced (optional): Actions connect your GPT to external APIs via OpenAPI schema — skip for your first build.

Part B — Create a Gemini Gem

Works on gemini.google.com with a Google account. Gems sync to mobile and Workspace side panels.

  1. Open Gem manager. Go to gemini.google.com → left sidebar → Gem manager → New Gem (or gemini.google.com/gems/create).
  2. Name your Gem. Short and functional: "Code Review Assistant", "Meeting Notes Summarizer".
  3. Write Instructions. Define: (1) persona/role, (2) primary task, (3) output format, (4) constraints. Use the same structure as a Custom GPT.
  4. Enhance (optional). Click the magic-wand / Enhance button to expand your draft — then review and trim anything that changes your intent.
  5. Add Knowledge (optional). Under Knowledge → Add files from your computer or Google Drive (brand guide, past examples, SOPs).
  6. Test in Preview. Use the right panel with real input. Check format, tone, and edge cases.
  7. Save & iterate. Click Save. Your Gem appears in the sidebar. Refine Instructions whenever output drifts.

Note: Gems are created on the web app; you can use them on mobile after sync. Gems don't work with Gemini Live yet.

Before You Build: Prep Checklist

  • Pick one narrow job — "review React PRs" beats "help with coding"
  • Draft instructions using the 6-step framework or Prompt Coach on the hub page
  • Gather 1–3 knowledge files (plain TXT is most reliable)
  • Write 3 conversation starters that show ideal usage
  • Define success: "Output must be markdown with Pass/Fail per criterion"

Intern Project Idea

Build one assistant for your capstone workflow:

Custom GPT: "My Code Reviewer"

Upload your team's style guide + paste review checklist in Instructions. Starters: "Review this PR diff", "Check for security issues".

Gem: "Daily Standup Writer"

Instructions: turn bullet notes into a structured standup (Yesterday / Today / Blockers). Upload past standup examples as Knowledge.

Checkpoint — Custom Assistants

  • Created one Custom GPT or one Gemini Gem with clear Instructions
  • Added at least one knowledge file or conversation starter
  • Tested with 3 real prompts and refined Instructions once
  • Shared the link with a teammate (or kept private with a documented use case)
