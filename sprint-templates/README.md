# Sprint Templates (from PromptWizard)

Reference foundation documents for AlrightTech intern sprint-driven development.

| File | Purpose |
|------|---------|
| `context.md` | Project goals, roles, features, scope |
| `tech.md` | Stack, API, database, auth, deployment |
| `uiux.md` | Colors, typography, components, accessibility |
| `sprints.md` | Full phased sprint plan with Cursor execution prompts |

**Source:** [PromptWizard](https://github.com/alrighttech/promptwizard) — AlrightTech internal intern platform.

## How interns use these

1. For a **new client project**: upload requirements in PromptWizard → generate your own four files → download ZIP.
2. For **learning**: read these examples, then draft the same four files for your capstone.
3. In **Cursor Plan mode**: attach `context.md`, `tech.md`, `uiux.md` + paste **one** Sprint Execution Prompt from `sprints.md` at a time.
