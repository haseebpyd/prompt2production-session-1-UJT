Chapter 2: Understanding LLMs

Large Language Models are the engine behind every AI coding tool you will use. This chapter explains how they work, what they can and cannot do, and which platforms to use.

2.1 What is an LLM?

A Large Language Model (LLM) is a deep learning model trained on massive text datasets. It predicts the next token (word or sub-word) in a sequence — this simple mechanism, scaled up, produces coherent code, explanations, and reasoning.

Input

Your prompt — instructions, code, context documents

Processing

Transformer self-attention weighs every word against every other word

Output

Generated text — code, explanations, plans, JSON, etc.

2.2 Key Concepts Every Developer Must Know

Tokens & Context Window

LLMs process text in tokens (roughly 4 characters each). The context window is the maximum tokens the model can see at once (e.g., 128K–1M). Longer context = more code/files you can include in one prompt.

Temperature

Controls randomness. Low (0–0.3) for deterministic code. High (0.7–1.0) for creative writing or brainstorming.

Hallucinations

LLMs can generate confident but incorrect information — fake APIs, wrong syntax, invented libraries. Always verify AI-generated code by running and testing it.

System vs User Prompts

In APIs and tools like Cursor, a system prompt sets persistent behavior (e.g., "You are a React expert"). User prompts are your specific requests per message.

2.4 From Chatbot to Coding Agent

Modern LLMs are not just chatbots. When connected to tools (file system, terminal, browser), they become agents that can read your codebase, run commands, and execute multi-step plans.

The Agent Loop (P-R-A):

Perceive
Read prompt + codebase
→
Reason/Plan
Break into sub-tasks
→
Act/Execute
Write code, run, deploy

Cursor and Antigravity (Chapter 6) wrap this agent loop inside your IDE. LangChain and CrewAI do it at the framework level for custom pipelines.
