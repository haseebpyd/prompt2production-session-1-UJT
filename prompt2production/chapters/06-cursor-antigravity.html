Chapter 6: Cursor & Antigravity

Move from browser-based LLMs to AI-native IDEs. These tools understand your entire codebase and become your primary development environment for the main journey.

6.1 Why AI-Native IDEs?

Traditional IDEs treat AI as an add-on. AI-native editors embed the LLM into every workflow — generation, editing, debugging, and refactoring — with full repository awareness.

Cursor

VS Code fork with deep AI integration. Chat, inline edit (Cmd+K), Composer for multi-file changes, and agent mode for autonomous tasks.

cursor.com

Antigravity (Google)

Google's agentic development environment. Strong Gemini integration, multi-agent workflows, and browser-based or IDE experiences for complex builds.

antigravity.google

6.2 Cursor Workflows

Chat (Cmd+L / Ctrl+L)

Ask questions about your codebase. "How does authentication work in this project?" — Cursor reads your files for context.

Inline Edit (Cmd+K / Ctrl+K)

Highlight code, describe the change. "Refactor this into a custom hook" or "Add error handling."

Composer / Agent Mode

Multi-file changes from a single prompt. "Add a settings page with dark mode toggle across the app." The agent plans, edits multiple files, and runs commands.

@ References

Use @file, @folder, @codebase to give the AI precise context in your prompts.

6.3 Setup Checklist

  • ✓ Install Cursor or Antigravity
  • ✓ Sign in and configure your preferred LLM model
  • ✓ Open your project folder (not just a single file)
  • ✓ Create a .cursorrules or project context file describing your stack and conventions
  • ✓ Initialize Git in your project before starting the main journey

Practical Exercise

Take your one-page app from Chapter 4. Open it in Cursor. Ask: "Split this into separate HTML, CSS, and JS files with a proper folder structure." Then: "Add a README and initialize git." This bridges your first build to the main journey.
