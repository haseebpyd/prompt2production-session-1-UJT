Chapter 4: Practical — One-Page App with Web LLMs

Your first hands-on build. No IDE, no setup — just a web browser, an LLM, and a text editor. Generate a complete single-file app and run it locally.

4.1 What You Will Build

A single-file HTML application — all HTML, CSS, and JavaScript in one file. Pick one:

Unit Converter

Temperature, length, or currency

Todo List

Add, complete, delete tasks — localStorage

Expense Tracker

Log expenses, show running total

Quiz App

Multiple choice with score tracking

4.2 Step-by-Step Workflow

1

Open a web LLM

Go to ChatGPT, Claude, or Gemini.

2

Write a structured prompt

Use the 6-step framework from Chapter 3. Copy the starter prompt below.

3

Copy the generated code

Paste into a file named index.html. Open it in your browser.

4

Iterate with follow-up prompts

"Add dark mode", "Fix the button alignment", "Add localStorage persistence" — refine until it works.

4.3 Starter Prompt (Copy & Customize)

Role: Act as a senior frontend developer specializing in vanilla JavaScript.

Task: Create a complete, single-file HTML todo list application.

Context: This is a learning exercise for an intern. The app must work by opening the HTML file directly in a browser — no build tools, no npm.

Constraints:
- Single file only (HTML + embedded CSS + embedded JS)
- Use Tailwind CSS via CDN
- Dark theme, fully responsive
- Store todos in localStorage so they persist on refresh
- Include add, complete (toggle), and delete functionality

Format: Output only the complete, runnable HTML file in a single code block. No explanations.

Checkpoint Before Moving On

  • Your app opens in the browser and all features work
  • You iterated at least 2–3 times with follow-up prompts
  • You can explain what each part of the prompt contributed to the output
