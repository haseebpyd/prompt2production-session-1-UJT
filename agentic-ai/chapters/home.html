This track continues beyond Prompt to Production. You will build the same primitives production AI teams use: multi-provider LLM calls, versioned prompts, structured outputs, RAG, agents, evaluation, and deployment.

Who This Course Is For

  • Developers, CS students, and graduates comfortable in Python who want to build AI products
  • Backend and full-stack engineers moving into AI engineering
  • AlrightTech interns continuing after the Prompt to Production foundation track
  • Not a deep ML-theory or model-training course — no heavy mathematics required

Prerequisites

  • Python (functions, classes, async basics)
  • Git/GitHub and the command line
  • REST APIs and JSON
  • Basic HTTP and environment variables

What You Will Be Able To Do

  • Build production RAG systems over private data with citations and measured quality
  • Design tool-using and multi-agent systems with memory, planning, and orchestration
  • Enforce structured outputs and integrate LLMs with external tools and APIs
  • Evaluate LLM/agent quality with datasets, metrics, and LLM-as-judge — catch regressions in CI
  • Add guardrails and defend against prompt injection and related LLM security risks
  • Deploy AI services with tracing, monitoring, cost control, and reliability patterns

How the Course Works

Rhythm: concept → live demo → guided lab → independent mini project. Roughly half of every module is hands-on building. Projects compound — each mini project feeds the next, and all converge into the Week 8 capstone.

Provider-aware

Claude, GPT, Gemini, and open models — not one-vendor lock-in.

Ship most days

Five days/week for eight weeks; working code is the default.

Assessed on delivery

Labs pass/fail; projects rubric-graded; capstone demo defense.
